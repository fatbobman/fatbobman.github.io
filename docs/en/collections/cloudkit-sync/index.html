Sync and Sharing

CloudKit lets Apple platform apps store, sync, and share data through iCloud. This collection maps the practical choices across Core Data with CloudKit, iCloud Documents, NSUbiquitousKeyValueStore, sync-status handling, and multi-device data architecture for indie and small-team apps.

Use the articles below for the larger CloudKit architecture story, then use related snippets for concrete repair work such as CloudKit model rules, macOS sync fixes, and initializeCloudKitSchema troubleshooting.

01

Core Data with CloudKit

Follow this path when you need Core Data persistence to sync through iCloud, including setup, model constraints, synchronization behavior, and live sync-state handling.

  1. Core Data with CloudKit: The Basics2021.08.05Core Data with CloudKit brings cloud storage and multi-device synchronization capabilities to Core Data applications. This article will introduce the basic knowledge of it.
  2. Core Data with CloudKit: Syncing Local Database to iCloud Private Database2021.08.09In this article, we will explore the most common scenario in Core Data with CloudKit applications—synchronizing the local database with the iCloud private database.
  3. Core Data with CloudKit: Exploring the CloudKit Dashboard2021.08.09This article explores the CloudKit dashboard.
  4. Core Data with CloudKit: Troubleshooting2021.08.10This article discusses some common issues encountered in developing Core Data with CloudKit projects, aiming to help everyone avoid detours and pitfalls.
  5. Core Data with CloudKit: Synchronizing Public Database2021.08.13This article will introduce how to synchronize a public database to the local environment, creating a local Core Data database mirror using Core Data with CloudKit.
  6. Core Data with CloudKit: Sharing Data in the iCloud2021.09.11In this article, we will explore how to create applications that share data with multiple iCloud users using Core Data with CloudKit.
  7. Switching Core Data Cloud Sync Status in Real-Time2022.07.26Core Data with CloudKit itself does not offer an option to enable or disable cloud synchronization in real-time. This article will attempt to propose a solution to this issue.
